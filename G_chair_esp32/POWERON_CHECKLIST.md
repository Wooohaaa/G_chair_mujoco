# 上电测试 Checklist（ESP32-S3 单缸验证）

按顺序做，每步打勾。目标：先让 1 个电缸动起来，再扩展到 6 个。

---

## 0. 准备

- [ ] ESP32-S3 DevKitC-1 一块，USB 线接电脑
- [ ] 日鼎伺服 + 独立 24V 电源（已接好）
- [ ] 杜邦线若干 + 2.2kΩ 电阻 ×3（缸1测试用）
- [ ] 万用表（测共地、测电压）
- [ ] 拆掉电缸负载（空载先测，或至少确保机械行程内无障碍）

---

## 1. 软件准备（电脑上）

- [ ] 确认已装 pyserial + websockets（ mujoco venv 里有 ）
- [ ] 给用户机烧录固件：

```bash
cd sim/G_chair_esp32
<platformio>/bin/pio run -t upload
```

- [ ] 启动调试面板（真实串口模式）：

```bash
cd sim/G_chair_hw
../G_chair_mujoco/.venv/bin/python debug_panel.py --port 8765
```

- [ ] 浏览器打开 `http://localhost:8765`，看到界面，串口列表里选 ESP32 的口，点"连接串口"
- [ ] 状态区显示 `使能 OFF`，`看门狗 正常`（等第一帧数据后变 ON）

---

## 2. 硬件接线（只接缸1）

| ESP32 | 经 2.2kΩ | 日鼎 DB25 | 说明 |
|---|---|---|---|
| GPIO4 (STEP0) | ──2.2k──→ | 8 (脉冲+) | 脉冲信号 |
| GPIO17 (DIR0) | ──2.2k──→ | 20 (方向+) | 方向信号 |
| GPIO12 (ENA) | ──2.2k──→ | 2 (使能) | 使能信号 |
| **GND** | ─────────→ | 14 (24V-) | **共地！必须接** |

> 伺服的 24V+（DB25-1）来自它自己的独立电源，不用动。
> 脉冲-/方向-（DB25-7/21）先不接或接 GND（单端测试）。

- [ ] 万用表确认 ESP32 GND 与伺服 24V- 导通（蜂鸣档）
- [ ] 确认 2.2kΩ 电阻串联在信号线上（不要直连）

---

## 3. 伺服参数（日鼎，按工程说明）

- [ ] 伺服上电，按日鼎说明书设置 PN 参数：
  - PN-01 = 5（1610 丝杠）或 10（1605 丝杠）——看你的丝杠导程
  - PN-02 = 1
  - PM-03 = 0
  - PN-04 = 1
  - PN-41 = 60（运行速度，报警就调低）
- [ ] 控制方式设为**位置模式**
- [ ] 伺服使能（使能针脚 DB25-2 有效）

---

## 3.5 板载自检命令（串口监视器）

烧录后用串口监视器（115200）发文本命令，快速确认固件alive：

```
#H   帮助
#E   使能驱动器
#D   禁止驱动器
#N   回中位
#T   逐轴点动自检：6 轴各走 +300 步(1.5mm) 再回中，用电机声/示波器确认
```

`#T` 空载时逐轴听电机是否动作、方向是否正确，不用等上位机。

## 4. 空载测试（拆掉电缸负载）

- [ ] 调试面板点"升沉+"，看状态区：缸1（第3个数字）目标应变成 +30mm
- [ ] 用示波器/逻辑分析仪测 GPIO4：应有脉冲输出，频率随目标距离变化（越近越慢）
- [ ] 没示波器就 servo 电机听声音/看轴转：点动作时电机应转动
- [ ] 点"中位"，电机停

---

## 5. 带载测试（装回电缸）

- [ ] 先手动把电缸摇到中位附近（避免上电猛冲）
- [ ] 点"中位"，确认平台不动
- [ ] 点"升沉+"，看缸1是否伸出（正向）
- [ ] 点"升沉−"，看缸1是否缩回（反向）
- [ ] **方向反了？** → 改 `config.h` 里 `PIN_DIR` 对应脚的逻辑，或调换伺服方向参数
- [ ] 点"软件急停"，平台回中位

---

## 6. 扩展到 6 缸

接线（都经 2.2kΩ）：

| 缸 | STEP GPIO | DIR GPIO |
|---|---|---|
| 1 | 4 | 17 |
| 2 | 5 | 18 |
| 3 | 6 | 8 |
| 4 | 7 | 9 |
| 5 | 15 | 10 |
| 6 | 16 | 11 |

- [ ] 逐轴接好，共地保持
- [ ] 面板"自定义位姿"输入 `[20,0,0,0,0,0]` → 只有缸1动
- [ ] 依次测 `[0,20,0,0,0,0]`、 `[0,0,20,0,0,0]` … 确认每缸对应正确
- [ ] 都对了 → 6 轴整合完成 ✅

## 7. 常见问题

| 现象 | 检查 |
|---|---|
| 电机完全不动 | 共地！使能信号！伺服参数！GPIO 配置是否正确 |
| 电机动但方向反 | 调换 DIR 或伺服方向参数 |
| 电机抖动/丢步 | 加 74HCT245 电平转换；线缆缩短 |
| 面板状态全 0 | 固件没烧状态回传版本；串口没连对 |
| 限位显示触发 | GPIO 配错或未接（悬空被误判），临时注释限位检测 |
