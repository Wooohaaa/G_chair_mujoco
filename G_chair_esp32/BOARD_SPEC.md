# ESP32-S3 六轴主控板 — 画板规格书

用**一块 ESP32-S3 开发板**替代原两块 Mega2560，驱动 Stewart 平台 6 个伺服电缸。
本文按功能分区块说明每个区块要做什么、用什么器件、连接关系，供画 PCB 用。

> 实物确认：伺服驱动（东能/日鼎/东菱）是 **24V 供电 + 差分脉冲输入**
> （Pulse+/Pulse-、Dir+/Dir-、使能），通过 RJ45 连接。见工程 `网口线序图.pdf`。
> RJ45 针脚：1=24V+ 2=24V- 3=使能 4=脉冲+ 5=方向+ 6/7=脉冲-/方向- 8=空。

---

## 总体框图

```
  USB-C (电脑)
       │ D-/D+ (GPIO19/20)
       ▼
┌─────────────────────────────────────────────┐
│  ESP32-S3 最小系统  (3.3V)                  │
│  RMT×6 产生 STEP      GPIO 控制 DIR/ENA      │
│  GPIO 输入 6×限位 + 急停                     │
└──────────┬──────────────────┬───────────────┘
           │ 单端 3.3V        │
           ▼                  ▼
┌──────────────────┐   ┌──────────────────────┐
│ 区块C: 电平转换   │   │ 区块E: 限位/急停输入  │
│ 3.3V→5V (74HCT245)│   │ 上拉+RC滤波+TVS      │
└──────────┬───────┘   └──────────────────────┘
           ▼
┌──────────────────────────────┐
│ 区块D: 差分驱动 AM26LS31 ×6  │  ← 关键！伺服要差分
│ 单端→差分(Pulse±/Dir±)       │
└──────────┬───────────────────┘
           ▼  RJ45 ×6  (每轴一个)
     伺服驱动器 (24V, DB25)
```

## 区块 A：电源

| 项 | 要求 |
|---|---|
| 输入 | **5V DC** 外部电源（DC 座或 2P 端子），给 ESP32 板供电 |
| 反接保护 | 串肖特基二极管（SS34）或 P-MOS 反接保护 |
| 3.3V 稳压 | LDO（AMS1117-3.3 / AP2112K-3.3，≥600mA，WiFi 峰值需 500mA） |
| 滤波 | 输入 10µF 电解 + 100nF；LDO 输出 10µF + 100nF + 1µF 靠近 ESP32 的 3V3 |
| 电源指示 | 红色 LED + 1kΩ 限流 |
| 注意 | **24V 不进这块板**——24V 只走 RJ45 到伺服驱动（针脚1/2），板子本身只处理信号和 5V→3.3V |

> 如果希望板子自己从 RJ45 的 24V 取电，需要加 DC-DC 降压 24V→5V（如 MP1584），
> 但建议先做简单版：独立 5V 供电，24V 只透传到 RJ45。

## 区块 B：ESP32-S3 最小系统

| 项 | 要求 |
|---|---|
| 模块 | **ESP32-S3-WROOM-1**（N8R8 带 PSRAM 更好，8MB Flash）或直接用 DevKitC-1 模块坐 |
| 供电 | 3.3V，每个 VDD 脚旁 100nF 去耦，至少 6~8 颗 |
| EN 复位 | 10kΩ 上拉到 3.3V + 100nF 到 GND（RC 延时），加轻触复位键到 GND |
| BOOT (GPIO0) | 10kΩ 上拉，加轻触下载键到 GND；或用 USB DTR/RTS 自动进下载电路（两颗 NPN） |
| Strapping | **GPIO45、GPIO46 下拉 10kΩ**（固定电平，避开启动歧义） |
| USB | GPIO19=D-、GPIO20=D+，各串 22Ω 电阻到 USB-C/Micro-B；加 ESD 保护（USBLC6-2SC6） |
| 天线净空 | 模块 PCB 天线区域板边 ≥15mm 内不覆铜、不放元件、不走线 |
| 注意 | 避开 strapping 引脚 **GPIO0/3/45/46** 作普通 IO；本设计已避开 |

---

## 区块 C：电平转换 3.3V → 5V

ESP32 的 GPIO 是 **3.3V 逻辑**，伺服/差分驱动器的输入建议 **5V  TTL**，必须转换。

| 项 | 要求 |
|---|---|
| 芯片 | **74HCT245**（8 路双向电平转换，5V 供电时输入兼容 3.3V）。**不要用 74HC245**（HC 在 5V 供电下不保证识别 3.3V 输入） |
| 数量 | **2 片**（6 STEP + 6 DIR + 1 ENA = 13 路，留 3 路备用） |
| 方向 | DIR 引脚接高电平（A→B，3.3V→5V），OE 接地常使能 |
| 输出串联电阻 | 每路串 100Ω，抑制振铃/过冲 |
| 供电 | 芯片 VCC=5V，旁边 100nF 去耦 |

---

## 区块 D：差分驱动 → RJ45（核心）

伺服驱动要**差分信号**，单端 3.3V/5V 直连长线会受干扰丢步。必须转差分。

| 项 | 要求 |
|---|---|
| 差分驱动芯片 | **AM26LS31**（4 路差分输出/片）或 SN75174。**需要 2 片**（6轴×2 路 = 12 路差分） |
| 供电 | 5V，每片 100nF 去耦 |
| 输出 | 每轴的 Pulse±、Dir± 接 RJ45 的 4/6 和 5/7 |
| 使能信号 | 使能（RJ45 针脚3）是单端，经 74HCT245 后直接输出（或也走差分，看伺服要求——工程原板是单端使能，按单端即可） |
| RJ45 连接器 | **6 个**（每轴一个），型号 R-RJ45S08P-C000（与工程一致，带 LED 的也行），直插或贴片 |
| RJ45 针脚定义（严格按工程） | 1=24V+  2=24V-  3=使能  4=脉冲+  5=方向+  6=脉冲-  7=方向-  8=空 |
| 24V 透传 | RJ45 的 1/2（24V±）直接接外部 24V 电源端子，**不与板子 5V/3.3V 共电源**，但 GND(2) 要与板子 GND 共地 |

> 每个 RJ45 的 24V+ 可以并到同一个 24V 输入端子（串保险丝，每轴 1A 自恢复保险丝），
> 24V- 与板子 GND 共地。

---

## 区块 E：限位 / 急停输入

| 项 | 要求 |
|---|---|
| 限位输入 | 6 路，GPIO {13,14,21,47,48,38}，上拉 10kΩ 到 3.3V，开关触发接 GND（LOW 有效，与固件一致） |
| 输入保护 | 每路串 1kΩ + 100nF 到 GND（RC 消抖）+ TVS（SMAJ3.3A）防浪涌 |
| 急停 (E-Stop) | **硬件级**：急停按钮直接切断 24V→使能 的回路（不经过 ESP32），同时把一个 GPIO（如 GPIO1 或任一空闲脚）拉低通知固件 |
| 急停指示 | 黄色 LED 亮表示急停按下 |
| 可选光耦 | 若现场干扰大，限位输入加 PC817 光耦隔离（6 路），隔离侧单独供电 |

---

## 区块 F：通信接口

| 项 | 要求 |
|---|---|
| 主通信 | USB（区块 B 的 GPIO19/20），电脑通过 USB 串口发 `<255><255>+6×16bit` 帧 |
| 预留 UART | 引出 UART0（GPIO43/44）排针，备用调试或接串口屏 |
| 预留 WiFi | ESP32-S3 自带，天线净空做好即可（将来可做 WiFi UDP 直连，甩掉 USB 线） |
| 预留 RS485（可选） | MAX485 + 120Ω 终端电阻，若将来远距离/多机控制 |
| 下载 | USB 自动下载电路（DTR/RTS → EN/BOOT），省去手动按键 |

---

## 区块 G：状态指示 / 调试 / 测试点

| 项 | 要求 |
|---|---|
| 电源 LED | 红，5V 指示（区块 A） |
| 运行 LED | 绿，任一空闲 GPIO，固件控制闪烁表示正常运行 |
| 使能 LED | 黄，ENA 有效时亮 |
| 复位键 / 下载键 | 区块 B 的轻触开关 |
| 调试接口 | 预留 SWD/JTAG 排针（TMS/TCK/TDI/TDO/GND/3.3V），方便烧录调试 |
| 测试点 | 5V、3.3V、GND、EN、GPIO0、各轴 STEP 信号，直径 1mm 测试点 |

---

## 区块 H：保护 / 抗干扰（工程特别强调）

工程多次强调抗干扰（原板在 RESET-GND 间加 10µF 电容）。对应到本设计：

| 项 | 要求 |
|---|---|
| EN 电容 | EN-GND 加 1~10µF（原 Mega 用 10µF），抑制复位脚干扰；注意太大需调整 RC 复位时间 |
| 电源入口 | π 型滤波：10µF + 磁珠 + 10µF |
| 去耦 | 每个 IC 电源脚 100nF，靠近引脚 |
| TVS | USB、RJ45 信号线、限位输入均加 TVS 防浪涌/ESD |
| 地处理 | 数字地单点接地；RJ45 的 24V-（地）与板子 GND 共地于一点；屏蔽线屏蔽层接机壳地 |
| 走线 | 差分线（Pulse±/Dir±）等长、相邻走、远离电源和数字信号；晶振/天线区域净空 |

## 引脚分配总表（与固件一一对应，画板时严格按此）

| 功能 | GPIO | 去向 |
|---|---|---|
| STEP 0~5 | 4, 5, 6, 7, 15, 16 | 区块C 电平转换 → 区块D 差分 → RJ45-4/6 |
| DIR 0~5 | 17, 18, 8, 9, 10, 11 | 区块C → 区块D → RJ45-5/7 |
| LIMIT 0~5 | 13, 14, 21, 47, 48, 38 | 区块E 限位输入 |
| ENA（低有效） | 12 | 区块C → RJ45-3（使能） |
| USB D- / D+ | 19 / 20 | USB-C |
| UART0 TX/RX | 43 / 44 | 预留排针 |
| BOOT / EN | 0 / EN | 下载键 / 复位键 |
| Strapping | 45, 46 | 下拉 10kΩ |
| 运行 LED | 任一空闲（如 GPIO2） | 绿 LED |

> 固件 `config.h` 已按此分配。若你画板时改了引脚，需同步改 `config.h` 的数组。

## 上板前检查清单

1. 空载测试：拆掉电缸，USB 接电脑，用逻辑分析仪看 6 路差分输出波形/频率是否随目标变化。
2. 确认 DIR 极性、ENA 有效电平（低有效），必要时改 `ENABLE_ACTIVE_LOW`。
3. 确认 RJ45 针脚与工程线序一致（1/2=24V±，3=使能，4/6=脉冲±，5/7=方向±）。
4. 确认 24V 只走 RJ45，不进板子低压部分；共地正确。
5. 逐轴接线，先用手托住电缸，验证方向、限位触发、急停。
6. 急停必须能在**不依赖固件**的情况下切断使能。

## 可选升级（第二版再考虑）

- 板载 DC-DC 24V→5V，直接从 RJ45 的 24V 取电，省掉外部 5V 电源。
- 编码器/磁栅尺反馈接口 → 闭环控制（当前开环）。
- 板载 CAN/RS485 多机级联。
- 换 ESP32-S3 + 外部 PSRAM 跑视觉（这样连 RK3566 都省了，但 YOLO 需另配 NPU——见前面评估，手机/S3 都不适合跑 YOLO，视觉仍建议留在 PC 或 RK3566）。
