# 最小可行方案：用现有硬件替代两块 Mega2560

现有硬件：**1 块 ESP32-S3 DevKitC-1** + **日鼎伺服（已带独立 24V 供电）**。
（可调升压模块暂时用不上——伺服电源已独立，ESP32 由 USB 供电即可。）

目标：替代原来的两块 Mega2560，让 6 个电缸按上位机指令动作。

---

## 1. 现有硬件能力评估

| 功能 | 现有硬件 | 结论 |
|---|---|---|
| 6 路步进脉冲 | ESP32-S3 的 8 路 RMT | ✅ 够 |
| 方向 / 使能 GPIO | DevKit 有 | ✅ 够 |
| 6 路限位输入 | DevKit 有 GPIO | ✅ 够（软件已支持） |
| 上位机通信 | USB-CDC | ✅ 够 |
| 状态回传 / 调试面板 | USB 串口 | ✅ 够 |
| 伺服 24V 供电 | **伺服已带独立电源** | ✅ 不用管 |
| 3.3V→5V 电平转换 | GPIO 只有 3.3V | ⚠️ 先试直连，不行补 74HCT245 |
| 单端→差分 | 无 | ⚠️ 短线可先不补，长线再补 AM26LS31 |
| RJ45 / DB25 接口 | 无 | ⚠️ 用杜邦线直连 DB25 先验证 |

**结论**：核心控制 100% 没问题。因为伺服电源独立，接线比原先设想的更简单——
ESP32 **只接信号线 + 共地**，不用碰 24V 电源。

---

## 2. 供电现状（简化）

```
【伺服系统】独立 24V 电源 → 6 个日鼎伺服驱动（已接好，不用动）
【ESP32】  USB 线接电脑 → 由 USB 供电（5V→板载 3.3V）
```

两边只需要做一件事：**共地**——把 ESP32 的 GND 和伺服的 24V-（GND）连起来，
否则信号没有参考地，伺服可能不响应。

> 可调升压板这次用不上。留着以后做"板上从 24V 取电"或电平转换时用。

---

## 3. 第一步：3.3V 直连测试（不买任何东西）

日鼎伺服 DB25 针脚定义（工程 PDF）：
```
1  = 24V+
2  = 使能
8  = 脉冲+
20 = 方向+
14 = 24V-
7/21 = 脉冲-/方向-
```

**先只用单端信号**（脉冲+/方向+），负端暂时不接或接 GND：

| ESP32 GPIO | 连接到 | 说明 |
|---|---|---|
| GPIO4 (STEP0) | 缸1 DB25-8 (脉冲+) | 经 2.2kΩ 电阻（原板参数） |
| GPIO17 (DIR0) | 缸1 DB25-20 (方向+) | 经 2.2kΩ |
| GPIO12 (ENA) | 缸1 DB25-2 (使能) | 经 2.2kΩ |
| GND | 缸1 DB25-14 (24V-) | 共地 |

> 先只接**一个缸**测试。用 2.2kΩ 电阻串联（和原板一样），
> 保护 ESP32 引脚也匹配伺服输入。

**测试步骤**：
1. 伺服独立电源上电，伺服使能（按日鼎说明书设置 PN 参数）
2. ESP32 接电脑，跑调试面板（真实串口模式）
3. 点"升沉+"或输入缸1位移 +20mm
4. **观察电缸动不动**：
   - ✅ 动了 → 3.3V 直连可行，按同样方式接其余 5 个缸
   - ❌ 不动 → 3.3V 门槛不够，需要补电平转换（见第 4 步）

---

## 4. 第二步（如需）：补电平转换

如果 3.3V 直连伺服不动作，花十几块买：

| 元件 | 数量 | 作用 |
|---|---|---|
| **74HCT245** | 2 片 | 3.3V→5V 电平转换（**HCT 不是 HC**，HC 在 5V 供电不识别 3.3V 输入） |
| 100nF 电容 | 若干 | 芯片去耦 |

接法：
```
ESP32 GPIO(3.3V) → 74HCT245 A端 → B端输出5V → 2.2kΩ → servo DB25
74HCT245 VCC=5V (从 ESP32 DevKit 的 5V 引脚取), DIR=高(A→B), OE=低(使能)
```

---

## 5. 第三步（长线时）：补差分驱动

如果电缸线缆超过 30cm、或现场干扰大导致丢步，再补：

| 元件 | 数量 | 作用 |
|---|---|---|
| **AM26LS31** | 2 片 | 单端→差分（脉冲±/方向±） |
| RJ45 座 + 线 | 6 套 | 按工程线序接伺服 |

短距离测试（杜邦线 <30cm）可以不做这一步。

## 6. 完整接线表（第一步，单缸测试）

```
ESP32-S3 DevKit        日鼎伺服 DB25        伺服独立24V电源
--------------        -------------        --------------
GPIO4  ──2.2kΩ────→  8 (脉冲+)
GPIO17 ──2.2kΩ────→  20 (方向+)
GPIO12 ──2.2kΩ────→  2 (使能)
GND    ───────────→  14 (24V-) ←──────── 24V- (共地!)
                      1 (24V+) ←──────── 24V+

USB    ←→ 电脑(调试面板)
```

其余 5 个缸：STEP GPIO 5/6/7/15/16，DIR 18/8/9/10/11，同样经 2.2kΩ 接到各自伺服。

## 9. 风险提醒

1. **共地（最重要）**：伺服 24V- 必须和 ESP32 GND 相连，否则信号无参考地。
2. **使能逻辑**：日鼎伺服使能针脚 2，确认是高有效还是低有效，必要时改 `config.h` 的 `ENABLE_ACTIVE_LOW`。
3. **急停**：伺服系统原有的急停保持不变；软件急停用调试面板的按钮。
4. **限位**：先不接或用 GPIO 模拟，测试调试面板里限位显示是否触发。
5. **空载先测**：拆掉电缸，看脉冲波形；确认方向/使能正确再装电缸。
