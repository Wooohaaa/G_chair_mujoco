# 接线对照：原两块 Arduino vs 现在 ESP32-S3

> 依据：工程 `控制器接线原理图.pdf`、`网口线序图.pdf`、`servoController.ino`、
> `必看说明.txt`。日鼎伺服（你用的品牌）DB25 定义已核对。

---

## 一、原系统接线（两块 Mega2560 + 无源转接板）

### 1.1 整体结构

```
FlyPT(PC) ──USB#1──> Mega#1 (基础4轴: 电缸1~4)
          ──USB#2──> Mega#2 (额外2轴: 电缸5~6)

每块 Mega 的 GPIO ──转接板(2.2kΩ+0.1µF)── DB25自接线 ──> 各自伺服
24V开关电源 ──常闭急停── 各伺服 24V
```

**两块板之间没有任何连线**——各自独立插 USB 到 PC，靠 FlyPT 分别发帧协调。

### 1.2 Mega 引脚（来自 servoController.ino）

| 功能 | 1号板/2号板相同 | 说明 |
|---|---|---|
| STEP (脉冲) | GPIO **12, 2, 7, 45** | 每块板 4 路定时器 |
| DIR (方向) | GPIO **30, 31, 32, 33** | 每轴一个方向脚 |
| 限位(干簧管) | GPIO **18, 19** 等 | 经 2.2kΩ+0.1µF，6轴版未启用 |

### 1.3 每轴 DB25 自接线（日鼎定义，原理图标 8/20/7/21）

| DB25 针脚 | 功能 | 接哪里 |
|---|---|---|
| 1 | 24V+ | 24V 开关电源 + |
| 2 | 使能 | Mega 方向/使能脚（经 2.2kΩ） |
| 14 | 24V- | 24V 电源 -（与 Mega GND 共地） |
| 8 | 脉冲+ | Mega STEP 脚（经 2.2kΩ） |
| 20 | 方向+ | Mega DIR 脚（经 2.2kΩ） |
| 7 / 21 | 脉冲- / 方向- | 原板经 2.2kΩ 接出（单端，负端可悬空或接GND） |

> 原理图特别注明："数字代表开发板上的引脚号，脚号所在位置从实物板上找，
> 图片中位置仅为方便画图"——**以标号数字为准**。

### 1.4 电源与急停

```
24V/24A 开关电源 + ──→ 所有 DB25-1 (24V+)
24V/24A 开关电源 - ──→ 常闭急停开关 ──→ 所有 DB25-14 (24V-)
                                    └──→ 与两块 Mega 的 GND 共地
```

急停是**硬件级**：常闭按钮串在 24V 回路，按下直接断电，不依赖软件。

## 二、现在 ESP32-S3 接线（一块板替代两块 Mega）

### 2.1 整体结构（大幅简化）

```
PC(上位机) ──一根USB──> ESP32-S3 ──6路GPIO(经2.2kΩ)──> 6个DB25自接线 ──> 伺服
                            │
                            └──GND ──→ 与伺服 24V- 共地

伺服 24V 电源：独立供电（你已确认），不进 ESP32 板
```

**变化**：
- USB 从 2 根变 **1 根**
- 控制板从 2 块变 **1 块**
- 每轴接线方式相同（还是 DB25 + 2.2kΩ），只是 GPIO 换了

### 2.2 ESP32 GPIO 分配（config.h）

| 功能 | 电缸1 | 电缸2 | 电缸3 | 电缸4 | 电缸5 | 电缸6 |
|---|---|---|---|---|---|---|
| **STEP** | GPIO4 | GPIO5 | GPIO6 | GPIO7 | GPIO15 | GPIO16 |
| **DIR** | GPIO17 | GPIO18 | GPIO8 | GPIO9 | GPIO10 | GPIO11 |
| **LIMIT** | GPIO13 | GPIO14 | GPIO21 | GPIO47 | GPIO48 | GPIO38 |
| **ENA**（共用） | GPIO12 | | | | | |

### 2.3 每轴接线表（电缸1 为例，日鼎 DB25）

| ESP32 | 经 2.2kΩ | 日鼎 DB25 | 说明 |
|---|---|---|---|
| GPIO4 (STEP0) | ──→ | **8** (脉冲+) | 脉冲信号 |
| GPIO17 (DIR0) | ──→ | **20** (方向+) | 方向信号 |
| GPIO12 (ENA) | ──→ | **2** (使能) | 6轴共用一根 |
| **GND** | 直连 | **14** (24V-) | **共地！必须** |

> DB25-1 (24V+) 来自你独立的伺服电源，不接 ESP32。
> 脉冲-/方向-（7/21）先不接或接 GND（单端模式，和原板一样）。

### 2.4 6 轴完整接线表

| 电缸 | STEP→DB25-8 | DIR→DB25-20 | 限位←DB25(干簧管) |
|---|---|---|---|
| 1 | GPIO4 | GPIO17 | GPIO13 |
| 2 | GPIO5 | GPIO18 | GPIO14 |
| 3 | GPIO6 | GPIO8 | GPIO21 |
| 4 | GPIO7 | GPIO9 | GPIO47 |
| 5 | GPIO15 | GPIO10 | GPIO48 |
| 6 | GPIO16 | GPIO11 | GPIO38 |
| 使能(共用) | GPIO12 → 所有 DB25-2 | | |
| 地线 | ESP32 GND → 所有 DB25-14 (24V-) | | |

## 三、新旧对比总结

| 项目 | 原系统 | 现在 ESP32 |
|---|---|---|
| 控制板 | 2 块 Mega2560 | **1 块 ESP32-S3** |
| USB 线 | 2 根 | **1 根** |
| STEP 脚 | 12/2/7/45 (每板4路) | 4/5/6/7/15/16 (6路) |
| DIR 脚 | 30/31/32/33 | 17/18/8/9/10/11 |
| 每轴信号线 | DB25 8/20/7/21 + 2.2kΩ | **完全相同** |
| 24V 供电 | 原 24V 开关电源 | **你独立供电，不变** |
| 急停 | 常闭串 24V 回路 | **保留原样** |
| 限位 | 有接口但未启用 | GPIO13/14/21/47/48/38 (启用) |
| 电平 | 5V 直连 | 3.3V（先试直连，不行补74HCT245） |

## 四、关键注意事项

1. **共地（最重要）**：ESP32 GND 必须和伺服 24V-（DB25-14）相连，
   否则信号无参考地，伺服不响应。
2. **2.2kΩ 电阻**：和原板一样，每根信号线串联，保护 ESP32 引脚并匹配伺服输入。
3. **使能极性**：日鼎使能针脚 DB25-2，先确认高/低有效；不对就改 `config.h` 的 `ENABLE_ACTIVE_LOW`。
4. **急停**：用伺服系统原有的常闭按钮，直接切 24V，不依赖 ESP32。
5. **单端优先**：先只接脉冲+（DB25-8）、方向+（DB25-20），负端（7/21）悬空；
   若丢步/干扰再补 AM26LS31 差分。
6. **空载先测**：拆掉电缸，看 GPIO4 等是否有脉冲，确认方向正确再装电缸。
