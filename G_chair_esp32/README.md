# ESP32-S3 单板替代双 Mega2560

用**一块 ESP32-S3-DevKitC-1** 替代原来的两块 Mega2560，驱动 6 路 Stewart 平台电缸。

> 📘 **总体说明（为什么替代、新旧对照、职责、迁移步骤）**：`REPLACING_DUAL_MEGA.md`
> 📐 **画板规格（8 功能区块、器件、引脚）**：`BOARD_SPEC.md`
> 🔧 **固件安装/接线/安全逻辑**：本文下方

> 📐 **要自己画 PCB？** 见同目录 `BOARD_SPEC.md`——按功能分区块（电源/最小系统/
> 电平转换/差分驱动+ RJ45/限位急停/通信/指示/抗干扰）给出了完整画板规格和引脚分配表。
> 关键：实物伺服是 **24V 供电 + 差分脉冲输入（RJ45）**，必须加 AM26LS31 差分驱动，
> 且 3.3V→5V 要用 74HCT245。

## 为什么双核不是关键 / 为什么一块就够

- 两块 Mega 不是因为算力不够，而是每块只有 **4 个 16 位定时器**（驱 4 个轴）。
- ESP32-S3 有 **8 路 RMT** 硬件脉冲发生器，单芯片驱 6 路绰绰有余。
- 双核（或 RMT 硬件）的真正价值：**脉冲产生不占用 CPU**，可以开 WiFi/蓝牙
  或做监控而不干扰步进——比 Mega 的定时器中断方案更稳。

## 硬件连接（ESP32-S3-DevKitC-1）

| 信号 | 引脚 | 说明 |
|---|---|---|
| STEP 0~5 | 4, 5, 6, 7, 15, 16 | RMT 输出 |
| DIR 0~5 | 17, 18, 8, 9, 10, 11 | 方向 |
| ENA | 12 | 低电平使能（改 `ENABLE_ACTIVE_LOW` 可翻转） |
| LIMIT 0~5 | 13, 14, 21, 47, 48, 38 | 上拉输入，触发为 LOW |
| USB | GPIO19/20 | 保留给下载/日志（不改作它用） |

⚠️ **电平匹配**：ESP32-S3 是 3.3V 逻辑。多数伺服驱动器 STEP/DIR 要求 5V，
**必须加电平转换**（74HCT245 / 74HC245，方向 3.3V→5V）。ENA 同理。
共地、双绞屏蔽线。

## 协议（与原固件兼容，只把 4 轴帧扩成 6 轴）

```
<255><255> + 6×uint16 大端   （共 14 字节）
16-bit / 1.7 -> 步数 (0~38400)，中位 32768 -> 19200 (96mm)
脉冲周期 = 4000 / |目标-当前| us，钳位 [39, 4000]
```

电脑端用 `G_chair_hw/serial_bridge.py --single-board` 发这个格式：

```bash
cd sim/G_chair_hw
../G_chair_mujoco/.venv/bin/python -u serial_bridge.py \
    --single-board --port1 /dev/ttyUSB0 --verbose
```

## 编译 / 烧录

```bash
cd sim/G_chair_esp32
<platformio>/bin/pio run            # 编译（已验证 SUCCESS）
<platformio>/bin/pio run -t upload  # 烧录（接上板子）
<platformio>/bin/pio device monitor # 看日志
```

烧录后串口会打印 `ESP32-S3 6-axis ready`，每秒打印一次 6 轴当前/目标步数。

## 安全逻辑

1. 上电 **ENA 禁止输出**，收到第一帧合法数据才使能。
2. 任一限位触发 → 立即停该轴脉冲（不强制回退，避免顶死）。
3. **看门狗**：超过 500ms 无有效帧 → 6 轴回中位（平台自动放平）。
4. 无位置反馈（开环），与实物原状一致；如需闭环要加编码器/磁栅尺。

## 与原双板的差异

| | 原双 Mega | ESP32-S3 单板 |
|---|---|---|
| 控制板 | 2 块 | **1 块** |
| 脉冲方式 | 定时器中断 | **RMT 硬件**（更稳，不受 WiFi 干扰） |
| 串口帧 | 2×`<255><255>`+4轴 | 1×`<255><255>`+6轴 |
| 限位 | 无 | 6 路（新增） |
| 看门狗 | 无 | 500ms 回中位（新增） |
| 电平 | 5V | 3.3V（**需电平转换**） |

## 待办（上真实电机前必须做）

1. 空载测试：拆掉电缸，接示波器/逻辑分析仪看 6 路 STEP 波形与频率是否随目标变化。
2. 确认 DIR 极性、ENA 有效电平（改 `ENABLE_ACTIVE_LOW`）。
3. 逐轴上电，先用手托住电缸，确认方向、限位生效。
4. 限位开关位置：目前只做"触发即停"，回中位动作需结合实际机械行程调整。

> 不要直接带负载全速运行——固件虽已编译通过，但真实电机接线前务必空载验证。
