## 1. 原系统由哪几部分组成

`控制器（嘉立创打板）` 目录里的实物系统 = **两块 Mega2560 开发板** + **一块无源转接板**（打板）：

```
FlyPT Mover (PC)
   │ 两根 USB 串口
   ├─→ Mega#1 (刷 servoController.ino) ─┐
   └─→ Mega#2 (刷 servoController.ino) ─┤
                                        ├─→ 无源转接板 (2.2kΩ/100nF/RJ45/端子/急停)
                                        │      └─→ 6 个伺服驱动 (24V+差分脉冲)
                                        └─→ 24V 电源 + 常闭急停开关
```

### 原系统的全部功能点

| # | 功能 | 由谁实现 |
|---|---|---|
| 1 | 接收 FlyPT 串口帧 `<255><255>+4×16bit` | Mega 固件 |
| 2 | 行程映射 `pos/1.7 → 0~38400 步` | Mega 固件 |
| 3 | 4 路定时器产生步进脉冲，`4000/|diff|` 减速 | Mega 固件 ×2 块 |
| 4 | 方向 GPIO 输出 | Mega 固件 |
| 5 | 使能信号输出 | Mega 固件 |
| 6 | 5V TTL 信号 → 伺服（经 2.2kΩ 电阻） | 无源打板 |
| 7 | 24V 电源分配 + 急停（常闭串 24V） | 无源打板 |
| 8 | DB25 / RJ45 接口（各品牌伺服线序不同） | 无源打板 |
| 9 | 干簧管限位接口（2.2kΩ+0.1µF，6轴未启用） | 无源打板 |
| 10 | 抗干扰（RESET 10µF + 信号 2.2k/0.1µF） | 打板 + 固件说明 |

## 2. 整合后：一块 ESP32-S3 板承担全部

```
FlyPT/上位机 (PC)
   │ 一根 USB 串口（单帧 <255><255>+6×16bit）
   ▼
┌───────────────────────────────────────────────┐
│  ESP32-S3 单板（整合全部功能）                  │
│  ├─ ① 串口帧解析 (6轴)        ← 原功能1        │
│  ├─ ② 行程映射 /1.7           ← 原功能2        │
│  ├─ ③ 6路 RMT 步进脉冲+减速    ← 原功能3(两板合一)│
│  ├─ ④ 方向/使能 GPIO          ← 原功能4/5      │
│  ├─ ⑤ 74HCT245 3.3→5V 电平转换 ← 原功能6(升级)  │
│  ├─ ⑥ AM26LS31 单端→差分      ← 原功能8(升级)  │
│  ├─ ⑦ 24V 透传 + 急停常闭回路  ← 原功能7        │
│  ├─ ⑧ 6路限位(真正启用)        ← 原功能9(升级)  │
│  └─ ⑨ 抗干扰措施              ← 原功能10       │
└───────────────────────────────────────────────┘
   │ 6×RJ45 (统一线序) → 转接线 → 各品牌伺服 DB25
   ▼
6 个伺服驱动 (24V + 差分脉冲)
```

### 功能整合对照表

| # | 原功能 | 整合到新板的方式 | 状态 |
|---|---|---|---|
| 1 | 串口帧（2 帧各 4 轴） | 改为 1 帧 6 轴；固件 `parse_byte()` | ✅ 固件已实现 |
| 2 | `pos/1.7` 映射 | `mapToRange` 等价：`frame[i]/MAP_DIVISOR` | ✅ 固件已实现 |
| 3 | 4 定时器脉冲（×2 板） | **6 路 RMT 硬件**，周期 `4000/|diff|` 减速曲线保留 | ✅ 固件已实现 |
| 4 | 方向 GPIO | `PIN_DIR[6]` + rmt_start 前设方向 | ✅ 固件已实现 |
| 5 | 使能 GPIO | `PIN_ENABLE=12`，低有效，首帧才使能 | ✅ 固件已实现 |
| 6 | 2.2kΩ 单端直连 | **74HCT245 转 5V**（升级，原板无芯片） | 📐 画板设计中 |
| 7 | 24V + 常闭急停 | 板子走线透传 24V；急停常闭串 24V 回路（保留原机制） | 📐 画板设计中 |
| 8 | DB25/RJ45 多品牌线序 | **统一 RJ45 线序** + 板外转接线适配各品牌 DB25 | 📐 画板设计中 |
| 9 | 干簧管限位（未启用） | **6 路真正启用**，2.2kΩ+0.1µF，触发停轴 | ✅ 固件已实现 |
| 10 | 抗干扰 | EN 电容 + 2.2k/0.1µF + TVS + 单点共地 | 📐 画板设计中 |

## 3. 需要你决策的三个问题（影响画板）

### 决策 1：用 ESP32-S3 模块焊在板上，还是用现成 DevKitC-1 插排针？

| 方案 | 优点 | 缺点 |
|---|---|---|
| **A. 模块贴片（WROOM-1）** | 板子小、集成度高、量产方便 | 要自己设计 USB/复位/天线净空，难度高 |
| **B. DevKitC-1 插排针** | 最小系统现成，只画外围，成功率高 | 板子大、多个开发板坐 |

> 建议第一次做选 **B（DevKitC-1 坐）**：只画电平转换+差分+RJ45+电源+急停，
> 把 DevKitC-1 的排针插上去。等验证成功再考虑 A。

### 决策 2：输出 RJ45 还是 DB25？

- 原板两种都有（RJ45 网口版 + DB25 自接线版）。
- 伺服品牌不同 DB25 针脚不同（东能/日鼎/一川都不一样，见 `config.h` 注释）。
- **建议**：新板统一出 **RJ45**（你的伺服如果是日鼎，RJ45 线序就按工程图），
  这样一块板通吃；接其他品牌时用板外转接线。若你确定只用某一种伺服且想板上直接出 DB25，
  按 `config.h` 里的品牌表格布线。

### 决策 3：差分驱动要不要加？

- 原板是单端直连（无差分芯片），短线下能用。
- **建议加 AM26LS31**（升级项）：抗干扰好，30cm 以上线缆更稳。多几颗芯片，成本很低。

## 6. 关键提醒

1. **算法不在板子上**：加速度→姿态→缸位移的映射在电脑端 `motion_pipeline.py`，
   这块板只执行"6 轴位移→脉冲"。换板不影响已调好的体感参数。
2. **24V 不进低压电路**：24V 只经板子端子/RJ45 透传到伺服，ESP32 侧只有 5V/3.3V。
3. **急停必须脱离固件生效**：常闭开关直接切 24V 回路，不能只靠软件。
4. **伺服品牌线序**：接不同品牌伺服时用板外转接线，针脚定义见 `config.h` 注释和工程 `网口线序图.pdf`。
5. **未带真实电机验证**：固件编译通过但没接真实伺服跑过，务必空载→逐轴验证。
